# MVP 范围

## 核心用户流程

用户进入网站后，可以浏览岗位，使用关键词和条件筛选岗位，查看公司与岗位详情，并收藏岗位或记录投递进度。

## 第一版包含

- 岗位列表与分页
- 岗位详情
- 公司详情
- 关键词搜索
- 城市、公司类型、岗位方向筛选
- 岗位收藏
- 投递状态管理：待投递、已投递、笔试、面试、已录用、已结束
- 使用初始化数据或简单管理方式录入岗位

## 第一版不包含

- 自动采集招聘网站数据
- 用户注册与登录
- 多用户数据隔离
- AI 岗位匹配与简历解析
- 邮件、短信或微信提醒
- 完整的运营管理后台

## MVP 验收标准

- 根据 README 可以启动前端、后端和数据库
- 页面展示数据库中的真实岗位数据
- 搜索和多个筛选条件可以组合使用
- 可以查看岗位及所属公司的详细信息
- 收藏和投递状态在刷新页面后仍然保留
- 无效参数和服务异常有清晰、统一的提示
