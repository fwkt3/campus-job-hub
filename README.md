# Campus Job Hub

一个面向应届毕业生的秋招岗位信息网站。

## MVP 目标

第一版完成“浏览岗位 → 搜索和筛选 → 查看详情 → 收藏或记录投递状态”的基本闭环。

## 技术栈

- 前端：Vue 3、TypeScript、Vite、Element Plus
- 后端：Java 21、Spring Boot 4.1.1、Spring Data JPA、Maven
- 数据库：MySQL 8
- 版本管理：Git、GitHub

## 项目结构

```text
campus-job-hub/
├── frontend/    # 前端项目
├── backend/     # 后端项目
```
